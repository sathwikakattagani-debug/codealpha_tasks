# Language Translation Tool

## Project Description
The Language Translation Tool is a Python application with a graphical user interface (GUI) that translates text from one language to another using the Google Translate service through the `deep-translator` library.

## Features
- User-friendly graphical interface
- Enter text for translation
- Select source language
- Select target language
- Translate text instantly
- Copy translated text
- Clear input and output fields
- Supports multiple languages

## Technologies Used
- Python
- Tkinter
- deep-translator (Google Translate)

## Supported Languages
- English
- Telugu
- Hindi
- Tamil
- Kannada
- Malayalam
- French
- Spanish
- German
- Japanese

## How to Run
1. Install Python.
2. Install the required package:
   ```
   pip install deep-translator
   ```
3. Run the application:
   ```
   python gui.py
   ```
